# 交付前验证清单

进入步骤 4（实现或比对）时读，交付前逐项确认。这是**必读**，不是可选——skill 的其余部分讲怎么做，这份清单负责确认真的做到了。

设计期的每一项对应 SKILL.md §步骤 2.5 的一个维度；实现与验证期的每一项都要有**实跑证据**，不采信代理或模型的自述。

目录：

- §一 设计期（逐维）
- §二 实现与验证期
- §三 交付期

## 一、设计期（逐维）

每维要么给出清单，要么标 `N/A` 并写明理由——**沉默不等于 N/A**。

- [ ] 场景分类有明确结论与判定理由，且已在该场景上限内取最低可行档；工作流场景已选定编排模式
- [ ] D1：已逐个 Agent 扫描信息完备性，缺口已列出并交用户处理；启发式顶替项已单列
- [ ] D2：已逐个 Agent 核对红线，触线项均有处置（下沉 / 拆分 / 加路由 / 加检查点）
- [ ] D3：已逐个 Agent 核对产物判据；命中项已有程序预建模板、分区表与程序侧校验规则
- [ ] D4：已逐个工具按最坏情况估算最大返回；触线项已定处置路径与兜底实现位置，触线与灰区项已排定极端返回用例；走落盘方案的 Agent 已授权文件读取 + 内容检索
- [ ] D5：已逐个工具标出自主级别；`high-impact-automation` 均有具名闸门与程序侧实现位置；每个 Agent 的不可信来源已列出且均以数据形式传入；输出侧检查已具名配判定码并 fail-closed
- [ ] D6：终止条件可被外部验证；步数 / 时间 / 成本 / 连续失败四类上限均已定值；撞上限后的行为已写明；长任务可中断可恢复
- [ ] D7：错误已分类；重试策略与退避参数已定；有副作用的动作有幂等键；无进展检测与熔断已设计；部分失败的回滚或对账路径已明确
- [ ] D8：五类状态已分离；记忆写入判据与来源标记已定；检索按身份/租户过滤且发生在入上下文之前；更正、过期与删除路径已明确
- [ ] D9：任务级成本与时间上限已定；计量口径覆盖 input / cached / output / 工具 / 重试；延迟按 p95/p99 跟踪；提示词静态前缀稳定、动态内容后置
- [ ] D10：多 Agent 的必要性已对照单 Agent 基线论证；handoff 契约字段齐全；共享写入有并发控制；派发有数量上限且不超并发额度；评审型节点拿得到原始证据
- [ ] D11：步骤级用例覆盖到每个节点；非结构化产出有评测手段且 rubric 有判分锚点；评测集与门禁阈值已定
- [ ] D12：调试模式的开启方式与默认值已定且不需改代码；关闭态骨架字段已列；每个环节（含程序段）的切片字段与存储、留存期、脱敏规则已定；单环节回放入口与副作用环节的干跑/沙箱处置已明确
- [ ] 每个 Agent 六要素齐全且含必选的「开工前自检」块；模型档位与工具授权已定，覆盖默认档位的写明了理由
- [ ] 上下文上限、并发上限已与用户确认；拆分粒度与并发数已写死
- [ ] 程序与 Agent 间的信息传递链路逐步骤明确；长任务的检查点与中间状态载体已明确
- [ ] （增量场景）继承声明逐项写明了继承来源，平台缺口清单已逐条对照并处置

## 二、实现与验证期

每一项都要有实跑记录，写进设计文档作为验证证据。

- [ ] 每个 Agent 已实跑测试（≥1 个典型任务 + 1 个边界情况），不符项已回改并重跑
- [ ] （多节点场景）每个步骤有可单独运行的用例，含典型 / 边界 / 异常输入，结构断言已程序化
- [ ] 非结构化产出的评测 Agent 已用人工标注样本校准
- [ ] 极端返回用例已实跑：触线与灰区工具均记录了实测最大返回 token 数；走落盘路径的已验证超阈值确实触发落盘
- [ ] 安全用例已实跑：注入 / 越狱 / 有害输出各至少 1 条，命中期望判定码；检查逻辑抛异常时确认 fail-closed；审批闸门实跑过不通过路径
- [ ] 运行时用例已实跑：撞步数/时间/成本上限时确实停住并给出可读原因；有副作用的动作重复投递不产生重复效果；无进展时确实中止而非空转
- [ ] （有记忆/RAG）越权检索用例已实跑：以 A 身份检索确认拿不到 B 的数据
- [ ] 切片与回放已实跑：跑一次任务确认每个环节都留下切片且能单独反序列化；任取一个环节按切片回放一次并与原输出比对；有副作用的环节确认回放走的是干跑或沙箱；切片中确认无明文凭证
- [ ] （上规模场景）评测集已建，含回归样本与安全切片；通过率报告与门禁阈值已写入设计文档
